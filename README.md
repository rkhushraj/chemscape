# ChemScape

A 3D molecular viewer — search any compound or element and explore an interactive ball-and-stick, space-filling, wireframe, or surface model. Includes a reaction visualizer for chemical equations.

**Live app:** https://chic-dodol-8790fa.netlify.app

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
npx netlify deploy --prod --dir=dist
```
